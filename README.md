# eldriic/homebrew-tap

Homebrew casks for [eldriic](https://github.com/eldriic)'s apps.

```bash
brew tap eldriic/tap
brew trust eldriic/tap
brew install --cask wisperkit
```

| Cask | Description |
| --- | --- |
| [`wisperkit`](Casks/wisperkit.rb) | [WisperKit](https://github.com/eldriic/WisperKit) — private, on-device Whisper dictation for macOS |
